# 单车地图 2.3.0

发布日期：待定

## 主要变更

- 寻车页增加 `ESTIMATED` / `REFRESHED` 位置来源状态。
- 车辆位置未知或超过 2 分钟时，进入寻车页自动执行一次有界刷新。
- 返回前台时为过期当前位置执行一次重新获取。
- Activity 重建后恢复刷新后的目标坐标、上报时间和位置来源。
- 刷新失败或接口返回更旧位置时保持已有位置和来源。

## 升级说明

- 本版本为 `2.3.0`，首次构建的 `versionCode=203001`。
- 最低支持 Android 8.0（API 26）。
- `2.0.0` 及之后的正式版共用同一签名，可直接升级，本机设置和记录保留。

## 已知限制

- 地图估算寻车不是 BLE/UWB 近场测距。
- 2 序列 WD 车辆的 BLE 身份映射未纳入本版本。
- 租用车辆匿名接口不提供位置时，基础寻车仍无法工作。
