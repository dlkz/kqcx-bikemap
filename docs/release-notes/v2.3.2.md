# 单车地图 v2.3.2

发布日期：2026-11-19

本版汇总 2.1.1 之后至 2.3.2 的主要功能和修复。

## 主要变更

### 地图与寻车

- 新增地图估算寻车，根据车辆最后上报位置和手机当前位置显示估算距离与方向。
- 寻车页支持位置来源提示、过期位置自动刷新、返回前台重新定位及页面重建恢复。
- 优化定位采纳和方向可靠性；定位质量不足时隐藏方向，避免短距离或旧方向造成错误指引。
- 新增蓝牙寻车。当前仅在 1 序列车辆完成验证；2 序列车辆不支持。其他序列尚未验证，仅在车辆接口提供可匹配的蓝牙名称时尝试使用。
- 蓝牙寻车不提供精确测距或蓝牙方向；车辆租用后仍可保留已有位置和最近寻车记录。
- 车辆支持地图卡片和半屏列表两种展示方式；地图三击可平滑缩小一级。

### 编号与记录

- 更新内置车辆编号目录。名单来自应用内置的车辆编号目录，随版本更新；未列出的校区仍可通过完整 9 位车辆编号查询。
- 完善尾号匹配、最近生成和最近寻车记录；目录暂不可用时，完整编号查询仍可使用。
- 修复附近刷新与完整编号查询并发时可能丢失查询结果的问题。
- 修复清除本机记录后，在途查询可能重新写入旧编号的问题。

### 稳定性与隐私

- 修复展开列表中的“定位”未独立响应点击，以及系统定位关闭时重复显示入口的问题。
- 避免应用进入后台后继续发起由地图移动排队的附近车辆查询。
- 加强诊断日志边界：正式版不写系统 logcat，第三方接口正文不进入日志，并加强编号遮挡、落盘和历史损坏字符处理。
- 修复清除诊断日志与进行中导出之间的并发竞争，避免已清除报告再次生成或分享。
- 将蓝牙硬件标记为可选能力，并完善 Android 8/9 二维码保存权限说明。

## 配套工具

- 本版本 Release 不单独附加 BLE 工具压缩包。
- BLE 硬件验证工具 `0.1.10` 固定保存在仓库 `companion/ble-hardware-test/releases/`，供维护人员在获授权设备上进行现场 BLE 排查。
- 该工具独立安装，不属于 BikeMap 的必需组件，可与 BikeMap 并存，并且两者不共享应用数据。
- 部分功能需要联网、定位和附近设备权限；导出的诊断包可能包含敏感设备标识，请仅交给可信人员。

## 已知限制

- 车辆位置、状态和编号数据由第三方接口提供，可能出现延迟、偏差或缺失。
- 地图估算寻车使用最后上报位置，不属于 BLE、UWB 等精确近场测距。
- 蓝牙寻车目前仅确认 1 序列车辆可用，2 序列车辆不可用；其他序列尚未验证，无法保证稳定匹配。车辆接口未返回可匹配的蓝牙名称时，仅可使用地图估算寻车。
- 不同设备的蓝牙、定位、后台限制、通知渠道和锁屏策略可能影响功能效果。
