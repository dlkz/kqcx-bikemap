# 单车地图 2.3.2

发布日期：2026-11-19

## 主要变更

- 新增非 2 序列车辆的 BLE 近场辅助，仅在寻车页由用户主动开启并保持前台。
- 使用匿名车辆接口返回的 `xlc-...` 名称与现场 BLE 广播精确匹配；信号仅用于“很强 / 较强 / 较弱 / 丢失”分档，不换算精确距离或方向。
- 新增最近 3 条本地寻车快照，并在车辆被租用后保留已有位置。
- 优化定位采纳、方向可靠性、页面重建恢复、过期位置刷新和前后台切换。
- 更新内置车辆编号目录至 2026-11-07 六轮扫描并集，累计 5,595 个编号、8 个站点。
- 明确编号来源优先级：内置精确编号 > 本机自学习精确编号 > `seed` 号段推断。
- 目录不可用时禁用尾号和号段匹配，但仍允许直接查询完整 9 位编号。
- 修复附近车辆刷新与完整编号查询并发时可能丢失查询结果的问题。
- 修复清除本机记录后，在途查询可能重新写回自学习编号的问题。
- 避免应用进入后台后继续发起由地图移动排队的附近车辆查询。
- 正式版诊断日志只写应用私有目录，第三方接口正文不写入日志；写入前遮挡连续九位编号并加强落盘同步。
- 修复诊断日志清除与进行中导出之间的并发竞争。
- 修复展开车辆列表中的“定位”按钮未独立响应点击，以及系统定位关闭时重复按钮的问题。
- 将蓝牙硬件标记为可选能力，并补充 Android 9 及以下相册权限说明。

## 已知限制

- 2 序列车辆不支持 BLE 近场辅助。
- BLE 辅助依赖车辆接口返回可匹配的 `xlc-...` 广播名称，且不提供精确测距或方向。
- 租用中车辆或匿名接口不返回位置与蓝牙字段时，BLE 辅助可能不可用。
- 不同设备的后台限制、通知渠道和锁屏策略可能影响提醒及车辆预警送达。
