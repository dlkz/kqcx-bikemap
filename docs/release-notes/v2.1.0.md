# 单车地图 2.1.0

发布日期：2026-10-11

## 主要变更

- 新增诊断日志导出、手动清除和详细日志开关。
- 完整 9 位车辆编号不再依赖内置目录命中，可直接查询车辆位置。
- 更新车辆编号目录，新增江西科技师范大学（枫林校区）等站点数据。
- 修复前后台切换后定位显示异常。
- 修复提醒权限、车辆预警和编号查询相关反馈。
- 优化车辆列表顶部间距和相关权限说明。

## 升级说明

- 本版本为 `2.1.0`，`versionCode=201012`。
- 最低支持 Android 8.0（API 26）。
- `2.0.0` 及之后的正式版共用同一签名，可直接覆盖升级，本机设置和记录保留。
- `1.0.1` 及更早版本使用旧签名，必须先卸载旧版再安装；卸载会清除旧版应用数据。
- 正式 APK 文件名、大小和 SHA-256 以 Release 附件为准。

## 数据说明

- APK 和源码中的运行时车辆编号目录由多批扫描并集生成，包含 5,312 个编号和 8 个接口站点。
- `docs/developer-data/vehicle-number/` 的公开摘要描述最新单次验证扫描，包含 4,289 辆唯一车辆和 8 个接口站点，不等于运行时目录的全部范围。
- 完整车辆编号目录随源码和 APK 分发；日志仍遵循本机保存和脱敏规则。

## 已知限制

- 车辆位置、状态和编号数据由第三方接口及扫描结果提供，可能延迟、偏差或缺失。
- 不同设备的后台限制、通知渠道、锁屏和横幅策略可能影响提醒展示。
