# 单车地图 2.1.1

发布日期：2026-10-15

## 主要变更

- 提升车辆预警稳定性，增加检查总预算和兜底闹钟，修复警告通知补发及关闭后残留问题。
- 完善诊断日志边界，限制日志文件大小，导出改为流式后台生成。
- 修复编号查询后顶部车辆统计未及时更新的问题。
- 优化车辆预警权限引导、提醒设置跨权限页保留和地图缓存统计体验。

## 升级说明

- 本版本为 `2.1.1`，`versionCode=201101`。
- 最低支持 Android 8.0（API 26）。
- `2.0.0` 及之后的正式版共用同一签名，可直接覆盖升级，本机设置和记录保留。
- `1.0.1` 及更早版本使用旧签名，必须先卸载旧版再安装；卸载会清除旧版应用数据。
- 正式 APK 文件名、大小和 SHA-256 以 Release 附件为准。

## 已知限制

- 车辆位置、状态和编号数据由第三方接口提供，可能存在延迟、偏差或缺失。
- 部分 Android 版本可能限制后台启动定位前台服务；车辆预警会安全暂停，重新打开应用后恢复。
