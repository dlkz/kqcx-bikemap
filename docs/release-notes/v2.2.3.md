# 单车地图 2.2.3

发布日期：2026-11-02

## 主要变更

- 新增地图估算寻车：根据车辆最后上报位置和手机当前位置估算距离，并在设备支持时显示相对手机朝向的方向。
- 重构车辆列表为地图卡片与半屏列表两种形态，可在设置中选择默认样式。
- 修复旧定位回放和居中回调竞争，改善前后台切换后的地图定位表现。
- 三击地图改为平滑缩小一级，避免默认级别无效果和瞬时跳变。

## 升级说明

- 本版本为 `2.2.3`，首次构建的 `versionCode=202301`。
- 最低支持 Android 8.0（API 26）。
- `2.0.0` 及之后的正式版共用同一签名，可直接覆盖升级，本机设置和记录保留。
- 地图估算寻车不是 BLE/UWB 近场测距，车辆位置以接口最后上报数据为准。

## 已知限制

- 车辆位置、状态和编号数据由第三方接口提供，可能存在延迟、偏差或缺失。
- 地图估算方向依赖手机定位和方向传感器，不同设备与环境下的稳定性可能不同。
