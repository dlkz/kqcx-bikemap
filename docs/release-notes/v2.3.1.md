# 单车地图 2.3.1

发布日期：待定

## 主要变更

- 新增非 2 序列车辆的 BLE 近场辅助。
- 使用匿名车辆接口返回的 `xlc-...` 名称与现场 BLE 广播精确匹配。
- 使用平滑 RSSI 提供“很强 / 较强 / 较弱 / 丢失”分档，不换算精确距离或方向；远端信号只作面板提示，连续样本稳定进入较强档后才接管中央距离。短暂无广播先提示信号减弱，8 秒未恢复才确认丢失；方向箭头仍按地图位置和手机方向计算。
- 寻车刷新遇到车辆租用中时，静默保留已有位置，不再弹出“车辆已出租”提示。
- BLE 扫描只在寻车页由用户主动开启并保持前台，仅读取广播名称和信号强弱。
- 点击“开始寻车”或从二维码/最近生成跳转微信时保存最近 3 条本地寻车快照，并补充蓝牙名称。
- 继续支持寻车位置来源、过期位置自动刷新、定位重获取和页面重建恢复。
- 优化手机定位采纳和短距离方向判断，避免较差定位或旧方向造成反向指引。
- 修复附近车辆刷新与完整编号查询并发时可能丢失查询结果的问题。
- 修复清除本机记录后，在途查询可能重新写回自学习编号的问题。
- 避免应用进入后台后继续发起由地图移动排队的附近车辆查询。
- 正式版诊断日志只写应用私有目录，Debug 版本保留 logcat 调试；第三方错误正文不再写入日志，写入前继续遮挡九位车辆编号并加强落盘同步和损坏字符处理。
- 修复清除诊断日志与进行中导出之间的并发竞争；清除会作废旧导出，分享前会重新验证报告仍然有效。
- 修复展开车辆列表中的“定位”按钮未独立响应点击的问题。
- 修复系统定位关闭且车辆支持蓝牙寻车时，寻车页重复显示两个“开启系统定位”按钮的问题。
- 将蓝牙硬件标记为可选能力，并补充 Android 9 及以下相册存储权限说明。
- 更新车辆编号目录至 2026-11-07 六轮扫描并集，累计 5,595 个编号；该轮单次重扫发现 5,105 个编号。

## 升级说明

- 本版本为 `2.3.1`，当前 signed Release 构建的 `versionCode=2030159`（构建号 `59`）。
- 从本版构建号 `47` 起使用新版 `versionCode` 编码，旧版本使用的编码值保留为历史记录。
- 最低支持 Android 8.0（API 26）。
- `2.0.0` 及之后的正式版共用同一签名，可直接升级，本机设置和记录保留。

## 已知限制

- 2 序列车辆不支持 BLE 近场辅助。
- BLE 辅助需要车辆接口返回可匹配的 `xlc-...` 广播名称；未返回时继续使用地图估算寻车。
- BLE 信号只用于粗略远近分档，不是精确测距，也不提供 BLE 方向。
- 租用中车辆或匿名接口不返回位置与蓝牙字段时，BLE 辅助可能不可用。
