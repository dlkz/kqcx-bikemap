# 单车地图 2.3.1

发布日期：待定

## 主要变更

- 新增非 2 序列车辆的 BLE 近场辅助。
- 使用匿名车辆接口返回的 `xlc-...` 名称与现场 BLE 广播精确匹配。
- 使用平滑 RSSI 提供“很强 / 较强 / 较弱 / 丢失”分档，不换算精确距离或方向；远端信号只作面板提示，连续样本稳定进入较强档后才接管中央距离。短暂无广播先提示信号减弱，8 秒未恢复才确认丢失；方向箭头仍按地图位置和手机方向计算。
- 寻车刷新遇到车辆租用中时，静默保留已有位置，不再弹出“车辆已出租”提示。
- BLE 扫描只在寻车页由用户主动开启并保持前台，仅读取广播名称和信号强弱。
- 点击“寻找车辆”或从二维码/最近生成跳转微信时保存最近 3 条本地寻车快照，并补充蓝牙名称。
- 继续支持寻车位置来源、过期位置自动刷新、定位重获取和页面重建恢复。
- 优化手机定位采纳和短距离方向判断，避免较差定位或旧方向造成反向指引。

## 升级说明

- 本版本为 `2.3.1`，当前 signed Release 构建的 `versionCode=203143`。
- 最低支持 Android 8.0（API 26）。
- `2.0.0` 及之后的正式版共用同一签名，可直接升级，本机设置和记录保留。

## 已知限制

- 2 序列车辆不支持 BLE 近场辅助。
- BLE 辅助需要车辆接口返回可匹配的 `xlc-...` 广播名称；未返回时继续使用地图估算寻车。
- BLE 信号只用于粗略远近分档，不是精确测距，也不提供 BLE 方向。
- 租用中车辆或匿名接口不返回位置与蓝牙字段时，BLE 辅助可能不可用。
