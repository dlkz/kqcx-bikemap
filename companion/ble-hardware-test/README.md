# BLE 硬件验证工具

这是 BikeMap 的可选辅助工具发布文件区，不属于 BikeMap 应用运行组件。

## 当前版本

- 版本：`0.1.10`
- 发布包：[BLE-Hardware-Verification-0.1.10-Release.zip](releases/BLE-Hardware-Verification-0.1.10-Release.zip)
- SHA-256：[BLE-Hardware-Verification-0.1.10-Release.zip.sha256](releases/BLE-Hardware-Verification-0.1.10-Release.zip.sha256)

发布包内包含 APK、对应源码、mapping、README、发布说明、许可证和第三方声明。

## 使用边界

- 仅供本人所有、已获明确授权或依法允许检测的车辆与设备使用。
- 该工具独立安装，可与 BikeMap 并存，两者不共享应用数据。
- 部分功能需要联网、定位和附近设备权限。
- 导出的诊断包可能包含设备标识或其他敏感测试数据，请只交给可信人员，不要公开上传。

## 后续版本

新版本使用带版本号的新文件名放入 `releases/`，保留旧版本，并同步更新本页面的当前版本、发布包和 SHA-256 链接。
