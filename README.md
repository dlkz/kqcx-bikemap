# 单车地图

单车地图是一个用于查看地图中心附近共享车辆、按车辆编号生成二维码，并提供本地提醒的 Android 工具。

> **非官方工具**：与任何车辆品牌、运营平台及第三方服务均无隶属、合作或授权关系。
>
> **升级提示**：2.0.0 的签名与旧版不同，不能覆盖安装，也不能与旧版同时安装。安装 2.0.0 前请先卸载旧版；卸载会清除旧版应用数据。

## 功能

- **地图与车辆**：查看附近车辆的位置、电量、距离、状态和数据上报时间，支持定位与地图缩放。
- **二维码**：支持按 3–4 位尾号或完整 9 位编号生成二维码，可保存、复制、分享或跳转微信扫一扫。
- **提醒**：提供 15 分钟计时，支持提前 1、3、5、7、10 分钟提醒，以及响铃并震动、仅震动、静默通知。
- **车辆预警**：在高级设置中启用，可按 10 秒、30 秒、1 分钟、3 分钟或 5 分钟检测附近车辆。
- **外观与设置**：支持浅色、深色和跟随系统主题；可管理二维码链接、最近记录、车辆预警和地图缓存。

## 使用

1. 首次启动时阅读并同意免责声明。
2. 授予定位权限，查看当前位置和附近车辆。
3. 选择车辆生成二维码，或输入车辆编号后 3–4 位尾号/完整 9 位编号生成。
4. 点击左侧提醒按钮设置提醒；车辆预警需要在“高级设置”中开启。

## 安装与升级

- 请从 GitHub Releases 下载正式版 APK。
- 2.0.0 与旧版签名不同，不能覆盖安装或共存。
- 必须先卸载旧版，再安装 2.0.0。卸载会删除旧版的应用数据，包括本机设置和记录。

## 数据与权限

应用只在相关功能需要时申请定位、通知、精确闹钟等权限。查询车辆时，地图中心坐标会发送至第三方数据接口；地图瓦片由高德开放平台加载。提醒设置和最近车辆编号保存在设备本地，详细说明见 [PRIVACY.md](PRIVACY.md)。
