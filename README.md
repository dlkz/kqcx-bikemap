## 功能

- **地图与列表**：查看附近车辆的位置、电量、距离和状态；默认过滤不可用车辆，支持地图卡片和半屏列表，列表中的“定位”只移动地图。
- **地图估算寻车**：显示车辆最后位置、估算距离和方向；过期位置自动有界刷新，定位不可靠时隐藏方向，短暂降级最多保留 8 秒。
- **蓝牙寻车**：非 2 序列车辆在接口提供 `xlc-...` 名称时，可主动开启前台 BLE 扫描；仅辅助判断远近，不提供精确测距或 BLE 方向。
- **编号查询**：完整 9 位编号可直接查询；3–4 位尾号通过内置目录匹配。
- **最近记录**：本机保留最近 3 个二维码编号、最多 3 条寻车快照和 500 条编号补全记录；关闭保留或清除记录时一并删除。
- **二维码**：生成、保存到相册、复制链接或跳转微信扫一扫；临时图片 30 秒后自动删除。
- **提醒**：15 分钟计时，支持提前 1、3、5、7、10 分钟提醒；可选择响铃震动、仅震动或静默通知，重启和覆盖安装后自动恢复未结束提醒。
- **车辆预警**：按 10 秒、30 秒、1 分钟、3 分钟或 5 分钟检测当前位置 100 米内可用车辆；少于 3 辆提醒，恢复 4 辆以上解除。
- **设置与排查**：支持浅色、深色和跟随系统主题；可清理地图缓存、导出或清除本机诊断日志。

## 使用

1. 首次启动时阅读并同意免责声明。
2. 授予定位权限，查看当前位置和附近车辆。
3. 选择车辆查看信息、估算寻车或生成二维码；接近车辆后可按需开启蓝牙寻车（2 序列除外）。
4. 点击左侧提醒按钮设置提醒；车辆预警需要在“高级设置”中开启。

## 配套工具

正式 Release 可同时提供独立的 BLE 硬件验证工具，用于获授权设备的现场蓝牙排查。该工具不属于 BikeMap 的必需组件，可与 BikeMap 并存安装，两者不共享应用数据。

部分检查需要联网、定位和附近设备权限。导出的诊断文件可能包含设备标识或其他敏感测试数据，请只交给可信人员，不要公开发布。具体使用边界以该工具自身的隐私说明为准。

## 数据与权限

- **车辆查询**：附近查询会发送地图中心坐标；完整编号查询、寻车页自动刷新或主动刷新，还会发送车辆编号和查询坐标。
- **地图与微信**：地图瓦片由高德开放平台加载，瓦片坐标可推断当前浏览区域；微信仅在用户操作时跳转，并适用微信自身隐私规则。
- **蓝牙**：只在寻车页由用户主动开启且保持前台，用于匹配车辆广播名称；不上传扫描结果。
- **本地记录**：设置、最近编号、寻车快照和诊断日志仅保存在本机，并排除云备份与换机迁移；二维码文件名和复制链接可能包含完整编号。
- **诊断日志**：正式版不写系统 logcat，第三方接口正文不进入日志；用户可在“关于 → 问题排查”中主动导出或清除。
- **权限**：定位、蓝牙、通知、精确闹钟和旧版存储权限均在对应功能使用时申请。

完整的数据流、保留期限和权限说明见 [PRIVACY.md](PRIVACY.md)。
